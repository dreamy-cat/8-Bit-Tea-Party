 Раздел 1. Общее описание, платформа, структура проекта и документации


 Демка для изучения ассемблера и архитектуры процессора Intel 8086/87.
 Несколько анимированных эффектов, сколько успеем и что сможем. :)
 Дата старта: 01.06.2021.
 Дата выхода проекта: 31.12.2021 ну или раньше, как будет удобней.
 Дата выхода версии для фестиваля: 25.11.2021.
 Дата выхода финальной версии: 28.02.2022 с переносом на 01.01.2025... :)

 Платформа: ДОС-совместимая от условной версии 5.0, реальный режим.
 Процессор: Intel 8086(88) и математический сопроцессор 8087.
 Модель памяти: 64Кб для кода, данных и стека или минимальная модель.
 Расширенная память: не используется.
 Графический адаптер: IBM VGA, 256Кб, 6 бит на цвет, вся палитра 2^18 цветов,
  графический Х-режим, 320x240x8бит на цвет по таблице цветов.
 Звуковая карта: Adlib(OPL2), FM - частотная модуляция, только звук без музыки.
 Формат файла: .COM, 64Kb максимум и компилиция(ассемблирование) полная по
 всем исходникам без бинарных объектов или дополнительных библиотек.

 Краткие рекомендации по документации необходимой в проекте,  литературу и
ссылки можно посмотреть подробнее в файле описания платформы:

 - The 8086 Family User's Manual, 1979;
 - IBM, VGA, XGA Technical Reference Manual, 1992;
 - Michael Abrash, Graphics Programming Black Book, 1997;
 - YM3812 FM Operator Type-L (OPLII), Application Manual, 1994.
 - Tech Help 6.0!


 Раздел 2. Сборка и минимальный набор инструментов


 Файлы ассемблирования не вошли в репозиторий, поэтому для примера.

 assemble.bat: (Можно в файл с дополнениями или строкой по желанию).

 C:\NASM\nasm.exe demo.asm -o demo.com -f bin -O0 -w+ptr

 Строка создает бинарный файл типа .COM, директива ORG 100H, должна быть в
исходном тексте программы.

 Комментарии по строкам.
 1. rm - удалить предыдущий исполняемый файл, если он был;
 2. C:\... - ассемблирование исходного файла ассемблером NASM, но возможно
использование любого другого ассемблера на уровне совместимости с MASM первых
версий: MASM, TASM, NASM, FASM и других.
 3. demo.com - запуск исполняемого файла, если не требуется, то можно добавить
директиву rem в начало строки.

 Директивы ассемблера в коммандной строке:

 "demo.asm" - исходный файл для ассемблирования;
 "-o demo.com" - создание обьектного файла и его имя;
 "-f bin" - простой бинарный формат без участия линковки;
 "-O0" - отключение всех оптимизаций, включая сегментные регистры(см.док);
 "-w+ptr" - предупреждения при использовании ptr, для совместимости.
